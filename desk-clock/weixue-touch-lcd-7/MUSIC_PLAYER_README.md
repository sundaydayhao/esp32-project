# 音乐播放器功能说明

## 概述

本项目在ESP32-S3桌面时钟的基础上，添加了音乐播放器功能。音乐播放器位于屏幕下方，可以从SD卡读取并播放音频文件。

## 功能特性

### 已实现功能

1. **SD卡支持**
   - 通过SPI接口连接SD卡
   - 自动扫描SD卡中的音频文件
   - 支持的音频格式：MP3, WAV, AAC, M4A

2. **播放控制**
   - 播放/暂停按钮
   - 上一曲/下一曲切换
   - 音量调节滑块（0-100%）
   - 播放进度条显示

3. **UI界面**
   - 专辑封面占位符（带音乐图标）
   - 歌曲名称显示（支持滚动）
   - 播放时间显示（当前时间/总时长）
   - 播放状态显示（曲目编号、音量）
   - 美观的深色主题设计

4. **自动播放**
   - 歌曲播放完毕自动切换到下一首
   - 播放列表循环播放

## 硬件连接

### SD卡引脚配置

根据 `config.h` 中的定义：

```
SD_PIN_MOSI  -> GPIO 11
SD_PIN_MISO  -> GPIO 13
SD_PIN_CLK   -> GPIO 12
SD_PIN_CS    -> 由板载 CH422G 的 EXIO4 控制，不是原生 GPIO
```

**注意**：在 `Waveshare ESP32-S3-Touch-LCD-7` 上，TF 卡的 `CS` 不是 `GPIO10`。`GPIO10` 已被 RGB LCD 数据线占用，错误地把它当作 SD `CS` 会导致初始化超时。

### 推荐的SD卡模块

- 支持SPI接口的标准SD卡模块
- 工作电压：3.3V
- 支持FAT32文件系统

## 使用方法

### 1. 准备SD卡

1. 格式化SD卡为FAT32文件系统
2. 将音频文件（MP3、WAV等）复制到SD卡根目录
3. 文件名建议使用英文，避免特殊字符

### 2. 插入SD卡

将SD卡插入SD卡模块，确保连接正确。

### 3. 启动设备

设备启动后会自动：
- 初始化SD卡
- 扫描音频文件
- 显示音乐播放器界面

### 4. 播放控制

- **播放/暂停**：点击中间的橙色圆形按钮
- **上一曲**：点击左侧的蓝色按钮
- **下一曲**：点击右侧的蓝色按钮
- **调节音量**：拖动音量滑块

## 技术实现

### 音频播放器 (audio_player.c)

- **SD卡挂载**：使用ESP-IDF的FATFS和SDMMC组件
- **文件扫描**：递归扫描SD卡根目录，识别音频文件
- **播放列表管理**：维护最多100首歌曲的播放列表
- **状态管理**：使用互斥锁保护播放状态
- **后台任务**：独立任务处理播放进度更新

### UI界面 (ui_music_player.c)

- **LVGL组件**：使用LVGL图形库构建UI
- **事件处理**：按钮点击和滑块变化事件
- **实时更新**：每秒更新播放状态和进度
- **响应式设计**：适配800x480分辨率屏幕

## 注意事项

### 当前限制

1. **音频解码**：当前版本为模拟播放，未实现真实的音频解码和输出
2. **播放时长**：默认设置为180秒（3分钟），需要实际解码后获取真实时长
3. **音频输出**：需要添加I2S音频输出硬件和驱动

### 未来改进方向

3. **功能增强**

## 故障排除

### SD卡无法识别

1. 检查SD卡是否正确插入
2. 确认SD卡格式为FAT32
3. 检查GPIO引脚连接是否正确
4. 查看串口日志中的错误信息

### 找不到音频文件

1. 确认音频文件在SD卡根目录
2. 检查文件扩展名（.mp3, .wav等）
3. 确认文件名不包含特殊字符

### 播放器界面不显示

1. 检查UI初始化是否成功
2. 查看内存使用情况
3. 确认LVGL配置正确
