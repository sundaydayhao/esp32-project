# CarPal - 汽车小摆件 🚗🎙️

> ESP32-S3 驾驶陪伴小摆件 | 实时车速显示 + 共情语音响应 + 语音聊天

## 功能特性

- 🚀 **实时车速显示** - GPS获取车速，仪表盘弧形指示，颜色随速度变化
- 🎭 **共情陪伴** - 根据车速、加速度、转向自动生成情感响应并**语音播报**
- 🎙️ **语音交互** - 说出唤醒词"小车伴"后可语音聊天和查询
- 📊 **行程统计** - 最高速度、平均速度、行驶里程
- 🔄 **模拟模式** - 无GPS/IMU时自动模拟驾驶数据，方便开发测试

## 硬件配置

### 必需组件
| 组件 | 型号 | 说明 |
|------|------|------|
| 主控 | ESP32-S3 | 双核240MHz |
| 显示屏 | ST7789 240×240 | SPI接口彩色LCD |
| TTS语音合成 | SYN6288 | UART接口，中文语音播报 |
| 语音识别 | HLK-V20 | UART接口，离线中文识别 |

### 可选组件
| 组件 | 型号 | 说明 |
|------|------|------|
| IMU | MPU6050 | I2C，检测转向/急刹/颠簸 |
| GPS | 任意NMEA模块 | UART，获取实时车速 |

### 引脚定义

```
ST7789 LCD (SPI2):
  MOSI  -> GPIO 11
  SCLK  -> GPIO 12
  CS    -> GPIO 10
  DC    -> GPIO 13
  RST   -> GPIO 14
  BL    -> GPIO 15

MPU6050 IMU (I2C0):
  SDA   -> GPIO 8
  SCL   -> GPIO 9

GPS 模块 (UART1):
  RX    -> GPIO 18  (接GPS TX)
  波特率: 9600

SYN6288 TTS (UART2 TX):
  GPIO 19 -> SYN6288 RX
  波特率: 9600

HLK-V20 ASR (UART2 RX):
  GPIO 20 <- HLK-V20 TX
  波特率: 9600
```

> 所有引脚可在 `main/config.h` 中修改

## 语音交互

### 唤醒和使用
1. 说出唤醒词：**"小车伴"**
2. 听到"我在，请说"后说出指令
3. 30秒无操作自动休眠

### 情感状态

| 状态 | 表情 | 触发条件 |
|------|------|----------|
| 开心 | `(^_^)` | 正常驾驶 60-100 km/h |
| 兴奋 | `(>_<)` | 急加速 / 高速行驶 |
| 担心 | `(>_<;)` | 超速 / 急减速 |
| 害怕 | `(o_O)` | 急刹车 / 危险驾驶 |
| 困倦 | `(-_-)` | 长时间低速 |
| 好奇 | `(o_o)` | 急转弯 / 颠簸路面 |
| 放松 | `(^_^)` | 平稳低速 / 停车 |
| 加油 | `(^o^)` | 堵车 / 低速拥堵 |

### 驾驶事件检测

| 事件 | 检测条件 | 语音响应示例 |
|------|----------|-------------|
| 急加速 | 加速度 > 25 km/h/s | "嗖的一下，好刺激！" |
| 急刹车 | 纵向G力 < -0.4g | "哎呀！急刹车！没事吧？" |
| 急转弯 | 偏航角速度 > 90°/s | "急转弯！我差点飞出去了~" |
| 超速 | 速度 > 120 km/h | "超速了！安全比时间更重要~" |
| 堵车 | 低速持续 > 30秒 | "堵车了，别着急，我陪你聊天~" |
| 颠簸 | 垂直G力变化 > 0.3g | "路面有点颠，抓稳了！" |
| 长途 | 行驶 > 1小时 | "开了好久了，累了吗？" |

## SYN6288 TTS 协议

```
帧格式: 0xFD [LEN_H] [LEN_L] 0x04 0x00 [UTF-8文本]
  0xFD    - 帧头
  LEN     - 后续字节数 (CMD + ENC + TEXT)
  0x04    - 命令：UTF-8编码文本播报
  0x00    - 背景音乐：无
  TEXT    - UTF-8编码的中文文本

控制标签（嵌入文本中）:
  [v5]    - 音量5（0-9）
  [s5]    - 语速5（0-9）
  [p5]    - 音调5（0-9）
```

## HLK-V20 ASR 协议

```
接收帧格式: 0xAA [TYPE] [LEN] [DATA...] [SUM]
  0xAA    - 帧头
  TYPE    - 0x01=唤醒, 0x02=休眠, 0x03=识别结果
  LEN     - DATA字节数
  DATA    - 识别结果时为指令ID
  SUM     - 校验和（TYPE+LEN+DATA之和的低8位）
```

## 编译和烧录

```bash
# 设置 ESP-IDF 环境
. $IDF_PATH/export.sh        # Linux/macOS
%IDF_PATH%\export.bat        # Windows

# 进入项目目录
cd car-display

# 设置目标芯片
idf.py set-target esp32s3

# 编译
idf.py build

# 烧录并监视
idf.py -p COM3 flash monitor
```

### 首次编译

首次编译会自动下载托管组件（需网络）：
- `lvgl/lvgl ~8.3.0`
- `espressif/esp_lvgl_port ~1.4.0`

## 注意事项

1. **SYN6288 UTF-8模式**：代码使用 `0x04` 命令字节（UTF-8编码）。若模块不支持，改为 `0x01`（GBK）并将中文字符串转为GBK编码。

2. **HLK-V20 指令表**：需用HLK-V20配套工具烧录指令表，指令ID必须与代码中的枚举值一致。

3. **无GPS模块**：默认启用模拟速度（起步→加速→匀速→超车→减速→堵车→停车循环）。

4. **无MPU6050**：自动使用模拟转向数据。

5. **无PSRAM**：在 `sdkconfig.defaults` 中禁用 `CONFIG_ESP32S3_SPIRAM_SUPPORT`。

6. **VS Code 头文件报错**：`esp_err.h` 等找不到是正常的（需配置ESP-IDF路径），不影响 `idf.py build` 编译。
