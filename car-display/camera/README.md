# 车辆左右盲区视觉显示系统

基于 **ESP32-S3** 的车辆左右盲区实时摄像头显示方案，使用两个 OV2640 摄像头分别监控车辆左右两侧盲区，并将画面实时显示在 SPI LCD 屏幕上，配合转向灯信号自动切换显示模式。

## 效果预览

```
分屏模式 (默认):
┌─────────┬─────────┐
│ [L]     │ [R]     │
│  左摄像头 │  右摄像头 │
│ [绿框=安全]│[黄框=注意]│
├─────────┴─────────┤
│ L:15fps  ---  SPLIT│  ← 状态栏
└────────────────────┘

左转全屏模式 (打左转灯时):
┌────────────────────┐
│ [L]                │
│                    │
│   LEFT CAMERA      │
│  (左侧盲区全屏)     │
│  [红色闪烁=危险]    │
│      DANGER!       │
│      < LEFT        │
├────────────────────┤
│ L:15fps << LEFT L-FULL│
└────────────────────┘
```

## 硬件需求

| 组件 | 型号 | 数量 |
|------|------|------|
| 主控 | ESP32-S3 (带 PSRAM) | 1 |
| 摄像头 | OV2640 (DVP接口) | 2 |
| 显示屏 | ST7789 / ILI9341 SPI LCD 320x240 | 1 |
| 光耦隔离器 | PC817 | 2 |
| 电源 | 5V/2A | 1 |

## 硬件连接

### OV2640 摄像头 (两个摄像头共享 DVP 数据线)

| 信号 | ESP32-S3 GPIO | 说明 |
|------|--------------|------|
| XCLK | GPIO15 | 时钟输出 |
| PCLK | GPIO13 | 像素时钟 |
| VSYNC | GPIO6 | 垂直同步 |
| HREF | GPIO7 | 水平参考 |
| D0 | GPIO11 | 数据位0 |
| D1 | GPIO9 | 数据位1 |
| D2 | GPIO8 | 数据位2 |
| D3 | GPIO10 | 数据位3 |
| D4 | GPIO12 | 数据位4 |
| D5 | GPIO18 | 数据位5 |
| D6 | GPIO17 | 数据位6 |
| D7 | GPIO16 | 数据位7 |
| SDA | GPIO4 | I2C 数据 |
| SCL | GPIO5 | I2C 时钟 |

### 摄像头独立控制引脚

| 信号 | 左摄像头 GPIO | 右摄像头 GPIO | 说明 |
|------|-------------|-------------|------|
| PWDN | GPIO1 | GPIO3 | 电源控制 (高=掉电) |
| RESET | GPIO2 | GPIO46 | 复位 (低=复位) |

> **双摄像头切换原理**：两个 OV2640 共享同一组 DVP 数据线，通过各自的 PWDN 引脚实现分时复用。采集时先掉电一个摄像头，上电另一个，等待稳定后采集帧数据。

### ST7789 LCD 显示屏 (SPI)

| 信号 | ESP32-S3 GPIO | 说明 |
|------|--------------|------|
| MOSI | GPIO35 | SPI 数据 |
| SCLK | GPIO36 | SPI 时钟 |
| CS | GPIO34 | 片选 |
| DC | GPIO33 | 数据/命令 |
| RST | GPIO37 | 复位 |
| BL | GPIO38 | 背光 (PWM) |

### 转向灯检测

| 信号 | ESP32-S3 GPIO | 说明 |
|------|--------------|------|
| 左转向灯 | GPIO39 | 高电平有效 |
| 右转向灯 | GPIO40 | 高电平有效 |

> **转向灯接入方式**：通过光耦隔离器将车辆转向灯信号（12V）转换为 3.3V 逻辑电平后接入 ESP32-S3 GPIO。

### 转向灯信号隔离电路

```
车辆转向灯 (12V) ──[1kΩ]──┬── 光耦 PC817 阳极
                           └── 光耦 PC817 阴极 ── GND

光耦集电极 ── 3.3V
光耦发射极 ──[10kΩ]── GND
光耦发射极 ──────────── ESP32-S3 GPIO (输入)
```

## 显示模式

| 模式 | 触发条件 | 说明 |
|------|---------|------|
| 分屏模式 (SPLIT) | 默认/无转向 | 左右各占半屏，同时显示两侧盲区 |
| 左全屏 (LEFT_FULL) | 打左转灯 | 左摄像头全屏，便于观察左侧盲区 |
| 右全屏 (RIGHT_FULL) | 打右转灯 | 右摄像头全屏，便于观察右侧盲区 |
| 双闪分屏 (SPLIT) | 双闪灯 | 分屏显示两侧 |
| 待机 (IDLE) | 初始化中 | 显示系统信息 |

## 盲区警告系统

系统使用基于**边缘密度检测**的轻量级算法分析摄像头画面，无需额外传感器：

| 警告等级 | 边框颜色 | 触发条件 | 说明 |
|---------|---------|---------|------|
| 安全 | 绿色细框 | 边缘密度 < 30% | 盲区无明显物体 |
| 注意 | 黄色粗框 | 边缘密度 30%~50% | 盲区有物体 |
| 危险 | 红色闪烁框 | 边缘密度 > 50% | 物体距离较近 |

> **算法说明**：对画面中央区域进行降采样，计算相邻像素的绿色通道梯度，高梯度区域表示存在物体边缘。此方法计算量小（每帧约 1ms），适合实时处理。

## 编译与烧录

### 环境要求

- ESP-IDF v5.0 或更高版本
- ESP32-S3 开发板（带 PSRAM，推荐 8MB Flash + 8MB PSRAM）

### 编译步骤

```bash
# 进入项目目录
cd car-display/camera

# 设置目标芯片
idf.py set-target esp32s3

# 下载组件依赖 (esp32-camera)
idf.py update-dependencies

# (可选) 通过 menuconfig 修改引脚配置
idf.py menuconfig
# 导航到: 车辆盲区摄像头配置

# 编译
idf.py build

# 烧录并监控串口
idf.py -p COM3 flash monitor
# Linux/Mac: idf.py -p /dev/ttyUSB0 flash monitor
```

### 引脚自定义

通过 `idf.py menuconfig` 进入 **"车辆盲区摄像头配置"** 菜单可修改所有引脚：

- **摄像头引脚配置**：DVP 接口引脚 + 左右摄像头独立控制引脚
- **LCD 显示屏引脚配置**：SPI 引脚 + 背光引脚
- **转向灯检测引脚配置**：左右转向灯 GPIO + 防抖时间
- **摄像头采集参数**：分辨率、帧率、切换延迟
- **盲区警告阈值**：注意/危险边缘密度阈值

## 常见问题

### Q: 摄像头初始化失败
- 检查 DVP 数据线连接是否正确（D0-D7 顺序）
- 确认 PWDN 和 RESET 引脚连接正确
- 检查 I2C (SDA/SCL) 连接
- 确保摄像头供电正常 (3.3V，不能用 5V)
- 尝试增大 `CONFIG_CAM_SWITCH_DELAY_MS`

### Q: 画面颠倒或镜像
在 `camera_manager.c` 的 `init_esp_camera()` 函数中修改传感器参数：
```c
sensor->set_hmirror(sensor, 1);  // 水平镜像
sensor->set_vflip(sensor, 1);    // 垂直翻转
```

### Q: 转向灯检测不灵敏
- 调整 `CONFIG_TURN_SIGNAL_DEBOUNCE_MS`（默认50ms，可减小到20ms）
- 检查光耦隔离电路是否正常工作
- 用万用表确认 GPIO 电平是否达到 3.3V

### Q: 帧率低
- 减小 `CONFIG_CAM_SWITCH_DELAY_MS`（最小建议10ms）
- 降低摄像头分辨率：在 `camera_manager.c` 中将 `FRAMESIZE_QVGA` 改为 `FRAMESIZE_QQVGA`（160x120）
- 确保 PSRAM 正常工作（串口日志中应显示 PSRAM 大小）

### Q: LCD 显示异常或花屏
- 检查 SPI 连接，特别是 DC 引脚
- 尝试降低 `CONFIG_LCD_SPI_CLOCK_HZ`（如改为 20000000）
- 确认 LCD 控制器型号：ST7789 需要反色（`invert_color=true`），ILI9341 不需要

### Q: 内存不足
- 确认使用的 ESP32-S3 模块带有 PSRAM
- 检查 `sdkconfig.defaults` 中 PSRAM 配置是否正确
- 降低摄像头分辨率或减少帧缓冲数量（`fb_count=1`）

## 扩展方向

1. **超声波测距集成**：接入 HC-SR04 超声波传感器，将实际距离数据叠加到画面上，替代基于图像的估算

2. **毫米波雷达集成**：接入 LD2410 等毫米波雷达，提供更精确的物体检测

3. **录像功能**：接入 SD 卡模块，在转向时自动录制盲区视频

4. **WiFi 远程查看**：通过 WiFi 将摄像头画面推流到手机 App

5. **夜视增强**：配合红外补光灯，在夜间提升摄像头画面质量

6. **双摄像头同步**：使用外部帧同步信号实现真正的双摄像头同步采集（需要额外硬件）
