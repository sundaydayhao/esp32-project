# 老年人吃药提醒器 —— 原型设计方案

> 基于 ESP32 的智能吃药提醒设备，专为老年人设计，操作简单、提醒可靠、界面友好。

---

## 一、项目背景与目标

老年人常常需要每天按时服用多种药物，但由于记忆力下降、生活习惯不规律等原因，漏服或错服药物的情况时有发生。本项目旨在设计一款低成本、易操作的 ESP32 吃药提醒原型设备，帮助老年人按时、按量服药，同时支持家属远程查看服药情况。

### 核心目标

- ✅ 按设定时间发出声光提醒（蜂鸣器 + LED 闪烁）
- ✅ 大字体屏幕显示当前时间和提醒信息
- ✅ 一键确认"已服药"，停止提醒
- ✅ 通过 Wi-Fi 将服药记录上报到手机/云端（可选）
- ✅ 支持通过手机 App 或网页配置提醒时间

---

## 二、硬件选型

| 组件 | 型号 / 规格 | 说明 |
|------|------------|------|
| 主控 | **ESP32-S3** (推荐) 或 ESP32-WROOM-32 | 内置 Wi-Fi + BLE，算力充足 |
| 显示屏 | **2.4" TFT LCD (ILI9341, 240×320)** 或 1.8" ST7735 | 大字体显示，老人易读 |
| 蜂鸣器 | 有源蜂鸣器 5V | 发出提醒音 |
| LED | 红色 LED × 1 | 闪烁提醒 |
| 按键 | 轻触按键 × 2 | 确认服药 / 暂停提醒 |
| RTC 模块 | **DS3231** | 断电保持时间，精度高 |
| 电源 | 5V USB 供电 或 18650 锂电池 + TP4056 充电模块 | 便携或固定使用 |
| 外壳 | 3D 打印 / 亚克力盒 | 圆角设计，安全美观 |

> **为什么选 DS3231？**  
> ESP32 内置 RTC 在断电后会丢失时间，DS3231 带有独立纽扣电池，断电后仍能保持准确时间，适合老年人家庭场景。

## 四、功能模块设计

### 4.1 时间管理模块

- 上电后通过 Wi-Fi 连接 NTP 服务器同步时间（`pool.ntp.org`）
- 同步成功后将时间写入 DS3231 RTC
- 断网或断电后从 DS3231 读取时间，保证时间连续性
- 支持设置时区（默认 UTC+8 北京时间）

### 4.2 提醒调度模块

- 支持最多 **6 个每日提醒时间点**（早、中、晚各 2 次）
- 每个提醒可配置：
  - 提醒时间（HH:MM）
  - 药物名称（最多 8 个汉字）
  - 剂量描述（如"1 片"、"2 粒"）
  - 是否启用
- 提醒数据存储在 **NVS（Non-Volatile Storage）** 中，断电不丢失

### 4.3 提醒触发模块

提醒触发后执行以下流程：

```
触发提醒
   │
   ▼
屏幕显示大字提醒（药名 + 剂量 + 当前时间）
   │
   ▼
蜂鸣器响 + LED 闪烁（每 2 秒一次）
   │
   ├─── 用户按下"确认"键 ──► 记录"已服药" + 停止提醒
   │
   └─── 超时未确认（5 分钟）──► 升级提醒（持续蜂鸣）
                                    │
                                    └─── 再超时 5 分钟 ──► 推送通知给家属
```

### 4.4 确认与记录模块

- 按下确认键后：
  - 屏幕显示"✓ 已服药，请保重！"
  - 将记录写入 SPIFFS（JSON 格式）：`{"time":"2026-03-30 08:00","drug":"降压药","status":"taken"}`
  - 通过 HTTP POST 上报到后端服务（如有网络）
- 支持查看最近 7 天的服药记录（屏幕翻页显示）

### 4.5 配置界面（Web UI）

- ESP32 启动后开启 **Wi-Fi AP 模式** 或连接家庭 Wi-Fi
- 内置 Web 服务器（基于 ESP-IDF `esp_http_server`）
- 家属通过手机浏览器访问 `http://192.168.4.1` 进行配置：
  - 设置/修改提醒时间
  - 设置药物名称和剂量
  - 查看服药历史记录
  - 设置 Wi-Fi 信息（STA 模式）

### 4.6 显示界面设计

屏幕分为三种状态：

**① 待机界面（平时显示）**
```
┌─────────────────────┐
│   2026-03-30  周一  │  ← 日期
│      08:32:15       │  ← 大字时间
│  ─────────────────  │
│  下次提醒: 12:00    │  ← 下一次提醒
│  降压药  1片        │
└─────────────────────┘
```

**② 提醒界面（触发时显示）**
```
┌─────────────────────┐
│  ⚠  该吃药了！      │  ← 红色大字
│                     │
│    降压药  1片      │  ← 药物信息
│    08:00            │  ← 提醒时间
│                     │
│  [按键确认已服药]   │  ← 操作提示
└─────────────────────┘
```

**③ 确认界面**
```
┌─────────────────────┐
│                     │
│   ✓ 已记录服药      │  ← 绿色
│                     │
│   请保重，注意休息  │
│                     │
└─────────────────────┘
```

### 主要任务（FreeRTOS Tasks）

| 任务名 | 优先级 | 功能 |
|--------|--------|------|
| `time_sync_task` | 2 | 每小时 NTP 同步一次 |
| `reminder_check_task` | 3 | 每分钟检查是否到提醒时间 |
| `display_task` | 2 | 刷新屏幕显示（1 秒一次） |
| `buzzer_task` | 4 | 控制蜂鸣器和 LED 节奏 |
| `button_task` | 5 | 检测按键输入（中断方式） |
| `web_server_task` | 1 | 处理 HTTP 请求 |

   │
   ▼

   │
   ▼

## 十一、风险与注意事项

1. **时间精度**：ESP32 内置 RTC 漂移较大，必须使用 DS3231 保证时间准确。
2. **老人操作习惯**：按键反馈要明显（声音 + 视觉），避免误操作；字体不小于 24px。
3. **网络依赖**：设备应在无网络时仍能正常工作（离线模式），仅 NTP 同步和上报需要网络。
4. **电源稳定性**：建议使用 USB 固定供电，若用电池需考虑低电量提醒。
5. **隐私安全**：服药记录属于个人健康数据，上报时应使用 HTTPS，后端需做访问控制。
