## 详细接线图 / Detailed Wiring

### 1. 摄像头 OV2640 接线

OV2640 使用 DVP (Digital Video Port) 接口，需要 16 根信号线：

```
OV2640 模块          ESP32-S3
─────────────────────────────
VCC (3.3V)    ──── 3.3V
GND           ──── GND
XCLK          ──── GPIO10
SIOD (SDA)    ──── GPIO40
SIOC (SCL)    ──── GPIO39
D0            ──── GPIO15
D1            ──── GPIO17
D2            ──── GPIO18
D3            ──── GPIO16
D4            ──── GPIO14
D5            ──── GPIO12
D6            ──── GPIO11
D7            ──── GPIO48
VSYNC         ──── GPIO38
HREF          ──── GPIO47
PCLK          ──── GPIO13
PWDN          ──── 不连接 (NC)
RESET         ──── 不连接 (NC)
```

> **注意**: 如果使用 ESP32-S3-EYE 开发板，摄像头已内置，无需外接。
> 修改 `main/app_config.h` 中的 `#define BOARD_ESP32S3_EYE`。

---

### 2. 舵机接线

每个舵机有 3 根线：VCC (红)、GND (棕/黑)、信号 (橙/黄)

```
舵机              ESP32-S3
──────────────────────────────────
有害垃圾挡板舵机:
  VCC (红)   ──── 外部 5V 电源
  GND (棕)   ──── 公共 GND
  信号 (橙)  ──── GPIO1

可回收物挡板舵机:
  VCC (红)   ──── 外部 5V 电源
  GND (棕)   ──── 公共 GND
  信号 (橙)  ──── GPIO2

厨余垃圾挡板舵机:
  VCC (红)   ──── 外部 5V 电源
  GND (棕)   ──── 公共 GND
  信号 (橙)  ──── GPIO3

其他垃圾挡板舵机:
  VCC (红)   ──── 外部 5V 电源
  GND (棕)   ──── 公共 GND
  信号 (橙)  ──── GPIO4

传送平台舵机:
  VCC (红)   ──── 外部 5V 电源
  GND (棕)   ──── 公共 GND
  信号 (橙)  ──── GPIO5
```

> **重要**: 舵机 VCC 必须使用外部 5V 电源，不能直接使用 ESP32-S3 的 3.3V 或 5V 引脚
> (电流不足会导致 ESP32-S3 复位)。建议使用独立的 5V/2A 电源模块。

### 3. DFPlayer Mini 接线

```
DFPlayer Mini        ESP32-S3
──────────────────────────────────
VCC          ──── 3.3V 或 5V
GND          ──── GND
RX           ──── GPIO6 (通过 1KΩ 电阻)
TX           ──── GPIO7
SPK_1        ──── 扬声器正极
SPK_2        ──── 扬声器负极
```

> **注意**: DFPlayer Mini 的 RX 引脚需要串联 1KΩ 电阻，防止电平不匹配损坏模块。

### 4. LED 指示灯接线

每个 LED 串联 220Ω 限流电阻：

```
ESP32-S3 GPIO    220Ω电阻    LED    GND
─────────────────────────────────────────
GPIO35 ──────── [220Ω] ──── 红色LED ──── GND  (有害垃圾)
GPIO36 ──────── [220Ω] ──── 蓝色LED ──── GND  (可回收物)
GPIO37 ──────── [220Ω] ──── 绿色LED ──── GND  (厨余垃圾)
GPIO45 ──────── [220Ω] ──── 黄色LED ──── GND  (其他垃圾)
GPIO46 ──────── [220Ω] ──── 白色LED ──── GND  (系统状态)
```

## 颜色卡片制作 / Color Card Preparation

制作 4 种颜色的识别卡片 (建议尺寸: 10cm × 10cm):

| 卡片颜色 | 垃圾类型 | HSV 范围 |
|---------|---------|---------|
| 🔴 纯红色 | 有害垃圾 | H: 0-15° 或 345-360° |
| 🔵 纯蓝色 | 可回收物 | H: 195-265° |
| 🟢 纯绿色 | 厨余垃圾 | H: 75-165° |
| ⚫ 灰色/黑色 | 其他垃圾 | 饱和度 < 20% |

> **建议**: 使用彩色打印纸或彩色卡纸，颜色要鲜艳纯正，避免混色。
> 在光线充足的环境下使用，避免强烈背光。

## 电源需求 / Power Requirements

| 模块 | 电压 | 电流 | 说明 |
|------|------|------|------|
| ESP32-S3 | 3.3V | ~500mA | 含摄像头 |
| 5个舵机 | 5V | ~2A (峰值) | 同时运动时 |
| DFPlayer Mini | 3.3-5V | ~200mA | 播放时 |
| LED (5个) | 3.3V | ~25mA | 全亮时 |
| **总计** | **5V** | **~3A** | **建议 5V/3A 电源** |

## 注意事项 / Important Notes

1. **GPIO 电平**: ESP32-S3 所有 GPIO 为 3.3V 逻辑电平
2. **舵机供电**: 必须使用独立 5V 电源，与 ESP32-S3 共地
3. **摄像头**: OV2640 需要稳定的 3.3V 供电，建议加 100nF 去耦电容
4. **DFPlayer**: RX 引脚串联 1KΩ 电阻保护
5. **散热**: 长时间运行时注意 ESP32-S3 散热
6. **接地**: 所有模块必须共地 (GND 连接在一起)
