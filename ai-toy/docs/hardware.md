## 模块接线详情

### 1. INMP441 数字麦克风

INMP441 是 I2S 接口的 MEMS 数字麦克风，信噪比高，适合语音识别。

```
INMP441          ESP32-S3
─────────────────────────
VDD  ──────────── 3.3V
GND  ──────────── GND
SCK  ──────────── GPIO4  (I2S_SCK / BCLK)
WS   ──────────── GPIO5  (I2S_WS / LRCK)
SD   ──────────── GPIO6  (I2S_SD / DIN)
L/R  ──────────── GND    (选择左声道)
```

> **注意**: L/R 引脚接 GND 选择左声道输出，接 VDD 选择右声道。

### 2. MAX98357A 数字功放

MAX98357A 是 I2S 接口的 D 类功放，直接驱动 4Ω/8Ω 喇叭。

```
MAX98357A        ESP32-S3
─────────────────────────
VIN  ──────────── 5V (或3.3V，5V音量更大)
GND  ──────────── GND
BCLK ──────────── GPIO15 (I2S_BCK)
LRC  ──────────── GPIO16 (I2S_WS)
DIN  ──────────── GPIO17 (I2S_DATA)
SD   ──────────── 悬空   (不接则默认开启)
GAIN ──────────── 悬空   (默认9dB增益)

喇叭+  ─────────── 喇叭正极
喇叭-  ─────────── 喇叭负极
```

> **注意**: 
> - VIN 接 5V 时音量更大，但需确保 ESP32-S3 的 5V 引脚有足够电流
> - SD 引脚悬空时功放默认开启；接 GND 时静音

### 3. WS2812B RGB LED

WS2812B 是单线串行控制的 RGB LED，使用 ESP32-S3 的 RMT 外设驱动。

```
WS2812B          ESP32-S3
─────────────────────────
VCC  ──────────── 5V (或3.3V，亮度略低)
GND  ──────────── GND
DIN  ──────────── GPIO48 (RMT)
```

> **注意**: 
> - GPIO48 是 ESP32-S3-DevKitC-1 板载 RGB LED 的引脚，可直接使用
> - 如果使用外接 WS2812B，在 DIN 线上串联 33Ω 电阻可防止信号反射

### 4. 按键

使用 ESP32-S3 的 BOOT 按键（GPIO0），也可外接独立按键。

```
按键             ESP32-S3
─────────────────────────
一端 ──────────── GPIO0 (BOOT键)
另端 ──────────── GND
```

> **注意**: GPIO0 内部有上拉电阻，按下时为低电平，符合 `BUTTON_ACTIVE_LEVEL = 0` 配置。

## 电源注意事项

1. **USB供电**: 通过 USB-C 供电时，5V 引脚电流约 500mA，足够驱动所有模块
2. **独立供电**: 如需更大音量，可为 MAX98357A 单独提供 5V 电源
3. **去耦电容**: 建议在 INMP441 的 VDD 和 GND 之间加 100nF 去耦电容，减少噪声

## 常见问题

### 麦克风没有声音
- 检查 L/R 引脚是否接 GND（选择左声道）
- 检查 I2S 引脚连接是否正确
- 在 `app_config.h` 中确认 `MIC_I2S_SCK_PIN`、`MIC_I2S_WS_PIN`、`MIC_I2S_SD_PIN` 与实际接线一致

### 喇叭没有声音
- 检查 MAX98357A 的 SD 引脚是否悬空（不接则默认开启）
- 检查 I2S 引脚连接
- 确认 `SPK_I2S_BCK_PIN`、`SPK_I2S_WS_PIN`、`SPK_I2S_DATA_PIN` 配置正确

### LED 不亮
- ESP32-S3-DevKitC-1 板载 LED 在 GPIO48，确认配置正确
- 检查 WS2812B 的电源和数据线

### 按键无响应
- 确认 `BUTTON_PIN` 配置为 `GPIO_NUM_0`
- 检查 `BUTTON_ACTIVE_LEVEL` 是否为 0（低电平有效）
